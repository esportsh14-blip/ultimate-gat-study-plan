# The Ultimate GAT Study Plan

A single-page website for picking a study plan for the **General Aptitude Test (GAT / القدرات العامة)**.

Students choose between a **30-day (Sprint)**, **45-day (Momentum)** or **60-day (Foundation)** plan.
Clicking a plan opens a full **day-by-day schedule**, split between the two sections:

- **Verbal (لفظي)** — coached by **[Azooz](https://azoozgat.com/)**
- **Quantitative (كمي)** — coached by **[Tamer](https://tamergat.com/)**

## Features

- Bold, dark-themed editorial design with Qiyas-inspired teal branding
- Three timeline plans with auto-generated, phased day-by-day schedules (Foundation → Skill Building → Advanced & Timing → Mock & Review)
- Built-in mock-test days
- Fully responsive (mobile → desktop) and accessible (keyboard nav, focus states, reduced-motion support)
- **Zero dependencies** — everything (styles, logos, scripts) is embedded in one `index.html` file

## Usage

Open `index.html` in any browser. No build step, no server required.

## Hosting

To publish live, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).
The site will be available at `https://<username>.github.io/ultimate-gat-study-plan/`.
